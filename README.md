# 🛒 বাজার দর (BazarDor)

## 📝 Short Description

**বাজার দর (BazarDor)** is a responsive web application that helps users explore daily product prices, compare market prices, and track price changes. It provides a user-friendly interface with product categories, detailed price information, and secure authentication.

## 🛠️ Technologies Used

- **Next.js** — React framework and routing
- **React.js** — User interface development
- **Tailwind CSS** — Responsive styling
- **JavaScript** — Application logic
- **Better Auth** — User authentication
- **MongoDB** — Database management
- **REST API** — Product and market data integration
- **HeroUI** — UI components and forms

## ✨ Key Features

1. **Product Listing:** Browse daily essential products with their names, prices, units, and icons.
2. **Price Tracking:** View products whose prices have increased or decreased.
3. **Market Price Comparison:** Explore product details and compare prices across different markets.
4. **User Authentication:** Sign up and sign in securely using Better Auth.
5. **Responsive Design:** Enjoy a user-friendly experience on mobile, tablet, and desktop devices.
